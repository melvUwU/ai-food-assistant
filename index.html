01 · Objective
Project Objective

This project builds an AI-assisted workflow to find the best restaurant for a team of 8–12 people for an after-work dinner, choosing from five Bangkok areas: สยาม (Siam), อารีย์ (Ari), ทองหล่อ (Thonglor), อโศก (Asoke), and พร้อมพงษ์ (Phrom Phong). The central question answered is: "Which restaurant best suits a team dinner — and why?" All decisions are grounded in real data scraped from Google Maps, not personal opinions or guesswork. Restaurants are evaluated objectively across six weighted criteria, producing a ranked shortlist with clear reasoning.

🔄 02 · Workflow Overview
AI Workflow — Step by Step
1
Problem Framing
Define team size, target areas, and decision criteria before any data is collected.
2
Data Collection
Apify Google Maps Scraper collects restaurant listings, ratings, reviews, and metadata across all 5 Bangkok areas.
3
Data Storage
Raw scraped data is stored in Google Sheets, separated into raw tabs per area and a unified clean data tab.
4
Data Cleaning
Claude AI normalizes field formats, deduplicates entries, flags missing data, and fills gaps where possible.
5
Scoring
Each restaurant is scored across 6 weighted criteria totalling 100 points — rating, group fit, price, travel, data completeness, and uniqueness.
6
AI Analysis
Claude ranks all restaurants, surfaces insights, identifies trade-offs, and generates the Top 3 recommendations with reasoning.
7
HTML Output
The final ranked report is built as a single-page HTML file — this page — with live data from Google Sheets via CSV fetch.
03 · Tools Used
Tech Stack

Optional deployment for sharing the dashboard publicly as a hosted web page.
